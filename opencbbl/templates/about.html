📋 О проекте

Черный список ЦБ РФ — это общественный инициативный проект, созданный для повышения финансовой грамотности и защиты граждан от недобросовестных финансовых организаций.

Мы используем исключительно открытые официальные данные Центрального Банка России для предоставления достоверной и актуальной информации о компаниях с выявленными признаками нелегальной деятельности.

🎯 Цели проекта

  • Обеспечить свободный доступ к официальной информации о нелегальных финансовых операциях
  • Помогать гражданам избегать взаимодействия с мошенническими организациями
  • Создавать наглядную визуализацию географического распределения проблемных компаний
  • Повышать финансовую грамотность населения
  • Пропагандировать прозрачность и честность в финансовой сфере

📊 Источники данных

Все данные загружаются из официального API Банка России (ЦБ РФ):

  • API списка компаний с признаками нелегальной деятельности
  • Библиотека регионов РФ
  • Библиотека признаков нелегальной деятельности
  • Детальная информация о каждой организации
